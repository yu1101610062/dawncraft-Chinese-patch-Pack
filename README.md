## 新增汉化内容

相对原版仓库的 2.0.15 汉化补丁，本分支额外适配并补充了 DawnCraft 2.0.16_hf 中新增或变更的游戏内容，主要包括：

- Quest Giver 任务系统文本：覆盖 400+ 个当前版本任务文件，包含 NPC 对话、任务目标、交付条件、奖励提示、职业/公会相关任务链等内容。
- DawnCraft 数据包文本：补齐或更新自定义进度、死亡/Tricked 等新增进度、村民职业交易、公会大师交易、结构/战利品展示文本，以及 Brutal Bosses 相关 boss 展示文本。
- `vm-language` 资源包文本：补入 2.0.16_hf 当前版本新增语言文件，并同步更新旧版已覆盖但结构发生变化的语言条目。
- 数据包结构适配：移除原 2.0.15 补丁中已不适配当前整合包的数据文件，并按 2.0.16_hf 的当前数据结构重新整理补丁内容。

## AI 汉化说明

上述相对原版仓库新增或补齐的游戏内容由 AI 完成初译和补译，并基于原仓库已有旧版译文进行迁移、合并和校验。旧版仓库已经覆盖的既有译文优先保留；AI 主要用于 2.0.16_hf 新增内容、当前版本结构变化内容，以及旧版补丁未覆盖的文本。

AI 汉化模型：`gpt-5.3-codex-spark`
